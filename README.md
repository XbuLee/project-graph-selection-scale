# 选区等比缩放

用于 Project Graph 4.2.5 的独立扩展。框选一组节点后，以选区中心同步调整节点位置、字号及大小，内部圆弧的弯曲幅度同时缩放，保留节点和连线的身份及连接关系。

## 安装与操作

从 [GitHub Releases](https://github.com/XbuLee/project-graph-selection-scale/releases) 下载 `local.selection-scale.prg`，用 Project Graph 打开，在扩展页面点击“安装”。开发者本地打包后的文件位于 `dist/`。若快捷键尚未出现，在“设置 → 扩展”点击“重载扩展”。

结束文字编辑，框选需要缩放的节点，再**依次**按下以下按键（不是同时按）：

| 按键 | 操作 |
| --- | --- |
| K → S → S | 输入百分比，50 为缩小一半，200 为放大两倍；支持 10–1000 |
| K → S → − | 缩小到当前大小的 50% |
| K → S → = | 放大到当前大小的 200% |

可在“设置 → 扩展 → 选区等比缩放 → 快捷键”修改按键。一次撤销可以恢复整次缩放，macOS 用 Command+Z，Windows/Linux 用 Ctrl+Z。

`dist/选区缩放示例.prg` 是独立测试图，可以用它尝试操作。

## 分享

直接发送 `dist/选区等比缩放-v1.0.0-分享包.zip`。对方解压后，用 Project Graph 打开其中的 `local.selection-scale.prg` 并安装；`选区缩放示例.prg` 是练习用的图，不能作为插件安装。分享包中的 `使用说明.md` 写有完整操作步骤，不需要 Node.js 或源码。

安装包、分享包和源码包统一从 [GitHub Releases](https://github.com/XbuLee/project-graph-selection-scale/releases) 获取。源码目录的 `PUBLISHING.md` 说明发布流程，`.github/workflows/release.yml` 在推送 `v*` 版本标签后自动发布；仅推送 `main` 或重新运行分支检查不会创建 Release。

## 行为

- 选区内的节点围绕同一个中心移动，节点中心之间的距离按指定比例变化。
- 普通文本节点的字体、内边距、边框和圆角随原生字号缩放；普通文本节点作为起点的连线，其线宽、箭头和连线文字由原生程序随字号缩放。
- 选中分组框时，递归包含内部节点；同时选中父框和子节点不会重复缩放。分组框随后按原生规则包住内部内容。
- 支持文本、已加载的图片、SVG、LaTeX 公式。质点作为折线拐点移动，保留原生固定半径。
- 内部圆弧的 offset 同步缩放。只选中连线一端时，另一端保持原位，连线继续连接两个原节点。
- 取消、输入 100%、输入无效比例均不改图。锁定分组、只读协作工程、尚在编辑的节点会提前拦截。
- 不联网、不执行系统命令，不改应用的全局布局或视觉设置。缩放结果使用原生数据保存。

## 原生限制

这个版本提供可直接安装的扩展，**不能保证所有节点和所有装饰都严格按像素等比**：

1. 原生文本字号为整数，字号等级保存到两位小数。默认 32 号字在 50% 和 200% 下可准确缩放；例如 32 × 80% = 25.6，实际采用原生可保存的 26。插件使用实际字号重新计算节点尺寸并保持中心布局，避免保存重开时再跳变。缩放再反向缩放可能有取整差异，要精确回到原样请撤销。
2. 分组框的标题、留白，质点半径，以及非文本起点的线宽是原生固定尺寸；插件不强行改写这些数值。多重连线的分离距离、自环、虚线节距和部分折线路由也遵循原生规则。
3. 手动换行节点的原生最小宽度是 75。若缩小后超限，会在修改前提示需要的最低比例；可先切换自动宽度。图片和 SVG 的原图倍率限制为 0.1–10。
4. URL、引用块、音视频、自定义扩展节点、涂鸦以及旧版实验性 CR 曲线暂不支持。遇到这些类型会明确停止，不做部分缩放。

如果需要分组标题、自环、虚线和任意小数字号也完全一致，需要给主程序增加对应的持久化缩放属性；当前安装包不包含主程序改动。

## 开发与验证

```sh
npm ci
npm run check
npm test
npm run package
```

独立测试覆盖共同缩放中心、嵌套分组、内部与外部圆弧、手动换行、输入取消、失败恢复和真实 Comlink 消息通信。主仓库另有 `app/src/core/extension/SelectionScale.test.ts`，使用真实 TextNode、序列化器和两种历史管理器验证保存重开、撤销和重做。

`npm run package` 生成安装包、版本归档、分享 ZIP 与源码 ZIP，并重新读取安装包校验结构。已有的 `dist/选区缩放示例.prg` 会保留，避免覆盖练习结果；分享 ZIP 每次都包含新生成的原始示例。设置 `RELEASE_TAG` 时，打包会校验标签与插件版本一致。
